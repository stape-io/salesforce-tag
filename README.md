# Salesforce Tag for Server Google Tag Manager

The **Salesforce tag for the server Google Tag Manager (sGTM) container** allows you to integrate your website with Salesforce by sending Lead and Contact data directly to the Salesforce REST API.

This server-to-server integration helps improve data accuracy and security by communicating directly with Salesforce from your server, bypassing client-side tracking limitations.

## Features

The tag supports two operations:

- Create a Lead
- Create a Contact

## How to use

1. Add the **Salesforce tag** to your GTM Server container from the Template Gallery.
2. Set your **Salesforce instance domain** and **Access Token**.
3. Select the **Operation** you want to perform (Create a Lead or Create a Contact).
4. Set the field/value pairs for the data you want to send.
5. Set up a trigger to fire the tag on the relevant server-side event.
